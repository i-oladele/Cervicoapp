Private recovery codes replace SMS recovery. No SMS account, API key or payment is needed.

Registration displays a randomly generated private code. The participant must save it before proceeding. Existing users can generate a code from Home by confirming their current PIN. Replacement invalidates the previous code. The raw code is shown only in the immediate response; only its SHA-256 hash is stored.

Forgot PIN accepts the saved code and a new four-digit PIN. Successful reset atomically replaces the PIN and code, returns a replacement code to save, and revokes older sessions. Five failed recovery attempts cause a 15-minute lockout. The code itself has 128 bits of randomness. Keep codes private and separate from the phone/PIN where possible.

If both the PIN and saved code are lost, recovery requires the study team to verify identity; it cannot be automated without another trusted verification method. No identity-checked staff override is exposed in this app.

Deploy the Supabase function and frontend together. Existing Termii secrets may be removed; this code no longer uses them. Push notification configuration is separate and remains necessary for reminders.
